# Backlink Audit
Research date: 2026-08-19

## Method and limitation
No commercial backlink index (Ahrefs/Semrush/Majestic) is authenticated in this environment (the Ahrefs connector exists but requires OAuth the owner has not completed). This audit therefore relies on: (a) search-visible citations, (b) direct fetches of the most likely linking sites (all 7 client sites), (c) domain-restricted searches. That observes the links that matter for entity corroboration; a paid index should be run later for completeness.

## Findings
| Tier | Definition | Found |

| TIER A | Authoritative + relevant | **0** |
| TIER B | Useful legitimate references | **1** — the Instagram bio link on @skyboundscaling (profile link, nofollow by platform policy, currently not visibly indexed) |
| TIER C | Weak / low value | 0 found |

- Client sites (7/7 checked): zero links, zero mentions.
- Directories: zero listings, therefore zero citation links.
- Editorial: zero.
- Founder profiles: the founder Instagram carries **no link** to the site at all.

## Does the current backlink footprint provide enough independent corroboration for a relatively new company?
**No — and not marginally.** A one-year-old agency does not need hundreds of links, but it needs a minimum corroboration set that this brand entirely lacks: (1) one professional-network company page linking the domain, (2) two or three client credits from real, independently-owned domains, (3) one or two directory/database records, (4) at least one editorial or interview mention. Current count on all four: zero. The only inbound reference on the public web is a social bio link on an unindexed 135-follower profile.

EVIDENCE INSUFFICIENT: full referring-domain enumeration (requires a commercial index; recommend running Ahrefs/Semrush once, expected result near-empty).
