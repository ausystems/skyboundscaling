# 30 / 60 / 90 Day External Authority Roadmap — 2026-08-19
No ranking outcomes are promised. Success is defined as *evidence created*, which is what the company controls.

## DAYS 1–30 — Own the official record
**Goal:** every place a person or machine would look for the company's identity says the same five facts.
**Actions:** LinkedIn company page + founder position · both Instagram bios corrected · three client credit requests sent · GBP created if eligible · Crunchbase/Clutch status verified manually · site `sameAs` updated to the profiles that now genuinely exist.
**Evidence to expect:** 2–4 new indexable pages stating name + category + founder + URL; 0–3 client footer credits (client-dependent).
**Measure:** count of live official profiles carrying the identical identity block; count of independent referring domains.
**Success looks like:** a search for the exact brand name returns at least one official profile alongside the website.
**Do not chase:** editorial coverage, Wikipedia, directory volume, or more on-site schema.

## DAYS 31–60 — Independent corroboration
**Goal:** sources the company does not own begin describing it.
**Actions:** Clutch profile + 2–3 genuine client reviews · Crunchbase live · answer source-request queries weekly · pitch two podcasts · secure X and Framer showcase submissions · follow up (once) on unanswered client asks.
**Evidence to expect:** first verified reviews; first third-party page stating "Ahmad Khalid, Founder of Skybound Scaling"; possibly a first podcast booking.
**Measure:** number of Type C–F sources; number of distinct source types (target ≥4).
**Success looks like:** the founder→company relationship is stated somewhere the company does not control.
**Do not chase:** national press, paid placements, link volume.

## DAYS 61–90 — Diversity and disambiguation
**Goal:** enough agreeing sources that retrieval systems resolve the name to this company rather than a namesake.
**Actions:** publish/record 1–2 podcast or contributed pieces · one quality agency directory · Toronto business community involvement · Bing Places · re-run the full AI/search retrieval test set from `11` and compare against today's baseline · registry verification concluded.
**Evidence to expect:** 6–12 independent sources across 4–6 types, all stating the same identity.
**Measure:** re-test brand queries; count how many return the correct entity vs Skybound Realty / Skybound Entertainment.
**Success looks like:** "Skybound Scaling" plus any qualifier returns the agency, and a retrieval-grounded AI answer describes it correctly with a citable source.
**Do not chase:** volume for its own sake. Twelve agreeing sources beat two hundred scattered ones.

## Standing rule for all 90 days
Only do things that would still be worth doing if search engines did not exist. Every item above passes that test: a real professional profile, real client credits, real reviews from real clients, real interviews.
